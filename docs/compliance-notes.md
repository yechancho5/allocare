# Compliance Notes

The MVP should avoid direct financial advice and securities recommendations.

Required product constraints:

- Use educational framing such as "historically" and "simulation suggests."
- Do not promise returns or imply guaranteed outcomes.
- Do not tell users to buy, sell, or hold a specific security.
- Store API keys only on the backend.
- Treat financial profile data as sensitive.
- Show assumptions behind simulations.
- Include disclaimers near recommendations and simulation outputs.

The recommendation service should receive backend-calculated findings rather than asking an AI model to invent financial math.
