# Product Requirements

## Goal

Help financially inexperienced users begin investing with more confidence through education, simulations, portfolio intelligence, and explainable AI guidance.

## MVP Features

- Multi-input financial profile
- Risk questionnaire and 1-10 score
- Baseline portfolio recommendation
- Slider-based portfolio builder
- Conservative, Moderate, and Aggressive presets
- Allocation validation
- Alpha Vantage-backed expected return, volatility, covariance, and diversification score
- Goal-based projection chart
- Monte Carlo API endpoint
- Education modules
- Recommendation cards with educational disclaimers

## Out of Scope

- Brokerage sync
- Tax optimization
- Day trading
- Stock picking
- Guaranteed investment advice
